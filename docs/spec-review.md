# 夜勤明けの街：決まりの点検（kit docs/rules.md）

kit `docs/rules.md`（2026-11-21 版）の決まりを、この作品に当てて点検した記録。当てはまるものは全部満たす。当てはまらないものは理由を書く。
機械の検査は `npm test`・`npm run check`・`node tools/check-playtest.mjs .`・`npm run check:pixel`・`npm run check:pairs`・`npm run check:copy`・
`node tools/play-routes.mjs`（4 つの結末・店の戦い・戦いそのもの・順路外）で見ている。

## 当てはまらない決まり（理由）

| ID | 理由 |
|---|---|
| CHAT-01〜13 | チャットのゲームではない（一人称 3D）。 |
| UI-28・GD-28 | シム・時間制のゲームではない。屋上の 2 分間だけは時間制なので、残り時間は目標の欄に出す（kit の task timer）。 |
| PH-12・PUB-12 | 2D の作品向け。 |
| FR-22 | 続編ではない（新しい作品）。 |
| MG-11 | 撮影のミニゲームを使っていない。 |
| PUB-08・PUB-09 | ポータルそのものの決まり。この作品はポータルに一枚足すだけ。 |
| PUB-10 | 『みる風車』の系列ではない。 |
| OBJ-14（旧 G7 隠れる場所） | 撃ち合いの作品で、隠れて息をひそめる遊びがない。代わりに、追われる場面は「戸を閉める」「撃つ」「走る」で切り抜ける。安全な部屋（当直日誌のある 4 部屋）には敵が入らない。 |
| FR-15（部屋から出させる仕掛け） | 一部だけ。籠城の場面（屋上の 2 分）は「部屋から出ない」ことが目的なので、そこは逆にした。ほかの区画は、物音で寄ってくるゾンビが部屋から出させる。 |

## 気をつけて満たした決まり

| ID | どう満たしたか |
|---|---|
| FR-04・FR-09（最初の敵は段階を踏む） | 最初のゾンビは当直室の外の廊下でガラス越しに見せる（first_glass）。次は脚のない這う一体（crawler）で、照準を合わせると部位の札が出る（脚＝這う、頭＝即死）。三体目から歩いてくる。 |
| FR-05・FR-06（触れたら結果がはっきり） | 噛まれる＝体力が減り、つかまれる（「殴る」で振りほどく）。体力が 0 で死亡のカード（何に、どうして）→ 最後に日誌に書いた所から。ケースの中身もそのときに戻る。 |
| FR-08（敵は走る速さの 7 割まで） | 走るゾンビ（runner/jogger/rider）は 2.6 m/s、プレイヤーの走りは 3.8 m/s（68%）。 |
| FR-10・FR-11・FR-12 | game.json `approach`（視界の端・鼓動・揺れ）。うなり声は個体ごとの声（assets/sfx/z-groan-1〜6）で、近いほど大きい。 |
| FR-02 | 揺れ・ちらつきは kit の設定（弱める）に従う。血の表現は「あり／控えめ／なし」をケースの画面で選べる。 |
| DOT（ドットの 3D） | 家具・車・箱・人・ゾンビは全部スプライトスタック。新しい部品は kit に `yakinake-*` として足した（車 6 種・救急車・バス・ヘリ・救急カート・工具箱・銃の保管庫 3 状態・銃のケース）。物の絵はケースのドット絵（assets/icons、pixel-items.json）。 |
| CH（人物） | 10 人とも共通のリグのドット人形（性別が分かる服と髪）。立っている間は idle。 |
| MG（ミニゲーム） | 18 種。どれも 2 回まで（search-dark・lock-pick・timing が 2 回、ほかは 1 回）。1.24.0 の 10 種のうち 6 種（switchboard・tape-splice・torn-paper・safe-listen・knot-untangle・rubbing）を使った。 |
| AUD-01（話す人物は全員声） | 80 行すべてと主人公の思い 9 行に声（VOICEVOX を順番待ち API で）。ゾンビのうなり・噛みつき・倒れる声・叫び・破裂・吐く音も作った。 |
| MED（素材） | 画像・声・BGM はローカルの順番待ち API だけで作った。 |
| PH（スマホ） | 横持ち推奨（縦では一度だけ案内）。仮想スティック、撃つ（押し続け）・殴る・装填・持ち替え・手当て・ケースのボタン。スマホでは照準が近い部位に少し吸い付く。 |
| PUB | 共有ボタン（タイトルと結末）、games.autoarticles.net への道、SEO の meta、OG 画像はゲームの中の場面から、GA4。 |
| PRC | 4 つの結末・店の戦い・戦い・順路外を play-routes で通し、PC と 3 つのスマホの大きさで撮って見た。 |
