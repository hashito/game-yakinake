# ドット絵工房

Claude CodeでZIPのルートを開く場合は `.claude/skills/3d-pixel-game/SKILL.md` も利用できる。`pixel-workshop` 単体を作業フォルダにした場合は、このフォルダの `CLAUDE.md` が同じ安全境界と制作ループを案内する。

Claude Codeが日本語の指示から編集できる原画形式と、ゲーム用の画像を書き出すローカルツール。**作品内の全ゲームプレイアイテムは3D現物を含めてドット絵化する。**制作端末に Node.js 22 以上があれば使える。ここで作るのは、3Dゲームの物品画像・調査写真・短いエフェクト。立体小物の形状と当たり判定は [3Dドット絵制作ルール](../rules/3d-pixel-art-rules.md) に沿ってゲーム側で作る。

## すぐ試す

1. ZIP全体を展開し、このフォルダの `preview.html` をブラウザで開く。収録作例を選ぶと、原寸の輪郭、整数倍の拡大、駒ごとの表示時間、繰り返しのつなぎ目を確認できる。
2. Claude Codeの作業フォルダを `pixel-workshop` にする。ここにある `CLAUDE.md` が制作手順。下記のように日本語で依頼する。

> 作業台で拾う古い懐中電灯を作って。所持品用は24×24。輪郭だけでも向きが分かるように、レンズ側を太くして、赤い布を柄に一周巻いて。調べたときにだけ電池蓋の欠けに気付くよう、別の48×48の接写も作って。両方をPNGで書き出して。

> 水漏れの作例から、天井から油が落ちるアニメを作って。離れる直前は一瞬ためて、床を打つ駒は短く。飛沫が消えてからループさせて。着地点が跳ねないか確認して。

3. 自分で試すときも、ターミナルをこのフォルダで開く。次の2行で止水ハンドルと火花を書き出せる。

```sh
node render.mjs valve-wheel
node render.mjs breaker-spark
```

`out/<id>.png` は透過背景の横一列のシート、`out/<id>.json` は座標・駒時間・支点・繰り返し情報。プレビューの「自分の書き出し」から同名の2ファイルを一緒に選ぶ。そのまま制作に使える4作例のPNG・JSONは `samples/` に収録している。初回の書き出し先は空いている。改稿時は `recipes/` 内で原画を別名に複製し、そのIDで書き出す。検査は `node --test test.mjs`、引数の確認は `node render.mjs --help`。作品の全アイテム監査は `item-manifest.example.json` をコピーして台帳を作り、`node audit-items.mjs <pixel-items.json>` を実行する。

| 作例ID | 1駒 | 内容 |
|---|---|---|
| `valve-wheel` | 32×32 | 所持品に使う止水ハンドル。巻き布と四角い軸穴を残した全形 |
| `valve-detail` | 40×40 | 同じ道具の接写。穴の四辺と鋳肌の摩耗を読む調査用 |
| `breaker-spark` | 32×24 | 接点に火花が飛んで消える7駒。680msの単発 |
| `water-drip` | 24×32 | 管の継ぎ目から落ちて水が跳ねる9駒。1,240msのループ |

## 同梱game-kitの既存アイテム素材

`game-kit/assets/textures/item/` にある59個の256×256素材については、元ファイルを変更せず `../pixel-assets/items/` に32×32・最大12色・ディザなしのドット絵派生版を全件用意している。対応は `../pixel-assets/items/catalog.json`、一覧は `../pixel-assets/items/contact-sheet.png`。3Dドット絵作品では原則こちらをworld側の出発素材として使い、通常版をそのままアイテム表面へ貼らない。固有の鍵や工具など、ゲーム上の形そのものが重要な物はこの汎用テクスチャだけで済ませず、専用world/inventory/examineを作る。

## 原画の仕様

原画ファイルは UTF-8 のJSON。ファイル名の例は `valve-wheel.json`。IDには半角小文字・数字・ハイフンを使い、先頭は小文字または数字、全体で48文字以内。Windowsのデバイス予約名は使えない。レシピ中に別ファイルのパスやプログラムを記入する欄はない。

| 欄 | 値と意味 |
|---|---|
| `width`, `height` | 1駒の幅と高さ。各1〜64pxの整数 |
| `palette` | 1文字の半角記号と6桁の色を対応付ける。例 `"r": "#B85138"`。スペースを使わず、透明は予約記号 `.` で描く |
| `pivot` | 全駒共通の支点 `[x,y]`。左上は `[0,0]`。駒の内側に置く |
| `loop` | `true` で繰り返し、`false` で最後の駒まで |
| `frames` | 順番に並ぶ1〜32駒。各駒には `duration`（20〜5000ミリ秒の整数）と `rows`（縦の行数 × 横の文字数）を指定 |

最小の記入例。下の内容を `recipes/indicator.json` に保存して `node render.mjs indicator` を実行する。左上にある琥珀色の灯が明滅する。

```json
{
  "width": 4, "height": 4, "pivot": [1, 1], "loop": true,
  "palette": {"d": "#703D36", "a": "#F0B956"},
  "frames": [
    {"duration": 600, "rows": ["aa..", "ad..", "....", "...."]},
    {"duration": 300, "rows": ["dd..", "dd..", "....", "...."]}
  ]
}
```

## ゲームへの取り込み

画像と同名のJSONを作品の素材フォルダに置く。各駒の `x, y, w, h` をシート上の矩形として切り出し、`duration` ミリ秒だけ表示する。単位は画素、左上原点。配置したい位置に `pivot` を合わせる。3D空間では演出を起こす物の座標に取り付け、所持品の窓では元絵を整数倍に拡大する。

電気火花なら、感電する時刻はゲームの仕掛けが管理する。描画が1駒遅れたときに当たり判定まで延びないようにする。静止画は1駒で書き出せる。棚の上の実物と接写には、同じ巻き布・傷・方向を残す。

## 入出力の範囲

本ツールはZIP内で独立して動く。ファイルを生成する工程にパッケージ取得、外部API、APIキー、追加プラグインは必要ない。Claude Code自体の認証とモデル通信は、利用しているClaude環境の設定に従う。

原画の大きさ・駒数・記号・形式を検査し、入力先を `recipes/`、出力先を `out/` に固定する。既存の出力があれば停止する。配布したツールのソース・テストは同じフォルダにある。これはこの工房の実装に対する取扱範囲で、同梱の従来ゲーム全体の安全性評価とは別に扱う。

同梱ファイルを照合する場合は `SHA256SUMS.txt` を使う。Windowsではこのフォルダで `Get-FileHash .\render.mjs -Algorithm SHA256` を実行すると、レンダラーの値を照合できる。出典と同梱範囲は [出典メモ](ORIGIN.md) に記録した。
